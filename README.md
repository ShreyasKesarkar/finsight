# FinSight

### FinTech Transaction Intelligence Platform

FinSight is a transaction intelligence platform designed to analyze financial transactions, identify unusual activity, and help users investigate potentially suspicious transactions.

## Objectives

- Import and analyze transaction data from CSV files.
- Search and filter financial transactions.
- Visualize transaction trends and spending patterns.
- Identify potentially suspicious transactions using explainable rules.
- Provide risk scores and reasons to support further investigation.

## Planned Technology Stack

- **Frontend:** React
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Data Analysis:** Pandas, NumPy
- **Version Control:** Git and GitHub

## Planned Features

- CSV transaction ingestion
- Transaction search and filtering
- Financial analytics dashboard
- Rule-based anomaly detection
- Explainable risk scoring
- Investigation queue and status tracking

## Project Status

🚧 Under development.

Features and technologies may change as development progresses.

## Disclaimer

FinSight is an educational project. Its risk scores and anomaly flags are intended to support investigation, not to establish that a transaction is fraudulent.
